# چه چیزی واقعاً ممکن است

## بله، بدون هیچ کاری از طرف هدف

| هدف | روش | شرط |
|---|---|---|
| گوشی اندروید | ADB بی‌سیم | دیباگ بی‌سیم روشن باشد |
| گوشی اندروید | Meterpreter APK | کاربر یک‌بار نصب و باز کند |
| ویندوز | Meterpreter EXE | کاربر اجرا کند |
| ویندوز | RDP | پورت باز + رمز |
| دوربین IP | RTSP/HTTP | در شبکه باشد |
| وبسایت | همه‌ی ماژول‌ها | — |
| اکانت | evilginx2 | کاربر لینک را باز کند |

## نه، ممکن نیست

| خواسته | واقعیت |
|---|---|
| هک اینستا فقط با یوزرنیم | باید یا پسورد/کوکی داشت یا فیشینگ زد |
| خواندن پیامک اندروید ۱۳+ بدون روت | فقط پیامک‌های جدید از طریق اعلان |
| دیدن صفحه‌ی گوشی بدون ADB یا RAT | ممکن نیست |
| هک وای‌فای بدون مانیتور مود | ممکن نیست |
| DDoS واقعی از یک لپ‌تاپ | حجم درنمی‌آید، فقط تست بار |
| هک دوربین گوشی بدون هیچ اپ | باید یک‌بار دوربین باز شود |
